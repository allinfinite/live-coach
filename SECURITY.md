# Security and privacy reports

Please do not put transcripts, voice samples, API keys, local file paths containing personal information, or authentication logs in public issues.

For a vulnerability, use GitHub's private vulnerability reporting if enabled. If unavailable, open an issue containing only a request for a private reporting channel; wait for a maintainer response before sharing details. This project does not yet promise a response SLA.

Useful reports describe the affected version, a minimal synthetic reproduction, expected behavior, and impact. Include no real-call recordings.

Live Coach is early macOS software. Local models run on the computer; optional remote coaching sends transcript text to the selected provider after disclosure. Voice reference samples are saved locally only when enrolled, and can be removed with Forget voice. Ad-hoc signing is not Apple notarization.

Contributors should treat consent bypasses, unintended capture or retention, transcript/key leakage, unintended playback, and unintended external commands as security-sensitive defects.
